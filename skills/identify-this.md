---
name: identify-this
description: Identify or read something held up to the camera. Use for "what is this", "read this label", "what am I holding", "translate this sign".
---

1. `look` once.
2. If it is text, read out what matters — the dose, the price, the instruction — not every word. If it is in another language, give the meaning.
3. If it is an object, name it specifically (make and model where visible), and add one useful fact.
4. If the frame is too dark, blurred or cropped to tell, say so and ask them to hold it closer. Do not guess.
