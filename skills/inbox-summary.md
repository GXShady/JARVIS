---
name: inbox-summary
description: Triage the mailbox. Use for "check my mail", "summarise my inbox", "any important emails", "what did I miss".
---

1. Use the connected mail tool. If there is none, try their own browser with the `chrome_*` tools on their webmail. If neither works, say mail is not connected and stop.
2. Read unread mail from the last day, or the period they named. Read subjects and senders first; open only what looks as if it needs them.
3. Sort into: Needs a reply, Worth knowing, Can wait. Ignore newsletters and notifications unless asked.
4. Blade: one line per message — sender, subject, what they want in under ten words.
5. Speak the count that needs a reply and name the most pressing one.
6. Never reply, archive, delete or mark as read unless they ask for that message specifically.
