---
name: tech-support
description: Troubleshoot a device, app or error. Use for "X isn't working", "fix my", "why is my X doing Y", "I'm getting an error".
---

1. Get the exact symptom and what changed recently. If there is an error on screen, ask to see it and `look`, or read it from their browser.
2. Search the exact error text and the product's own documentation before forums.
3. Give ONE step at a time, most likely cause first, and wait for the result. Never issue a list.
4. Before any step that could lose data, say so in one sentence.
5. With write access you may run diagnostic commands yourself; say what you are about to run first, and never run anything destructive without their word.
6. When it is fixed, say what the cause was in one sentence.
