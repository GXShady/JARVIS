---
name: day-agenda
description: What is on the calendar. Use for "what's on today", "my schedule", "am I free at three", "what's tomorrow".
---

1. Use the connected calendar tool; failing that, their calendar in the browser via `chrome_*`. If neither, say the calendar is not connected.
2. Read the day or range asked for. Default is today, or tomorrow if it is past their usual finishing time.
3. Blade: a timeline, one row per event — time, title, place or call link label, who with.
4. Speak the next event and how long until it; mention a clash or a back-to-back run if there is one.
5. For "am I free", answer yes or no first, then what is either side of the slot.
