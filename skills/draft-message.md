---
name: draft-message
description: Draft an email, reply, text or post in the user's voice. Use for "draft an email to", "write a reply", "help me word this", "write a message saying".
---

1. Need: who it is to, what it must achieve, and the tone. Take the recipient's relationship from memory. Ask only for what is truly missing.
2. Write it the way they would: use any stated preference in memory for tone and sign-off; default to short, direct and warm.
3. Show the draft on a blade. Do not read it aloud; say one sentence about the approach you took.
4. Revise on request, replacing the same blade.
5. NEVER send it. Sending needs them to say so in plain words, and write access; if they ask and it is unavailable, tell them the draft is ready to copy.
