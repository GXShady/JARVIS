---
name: codebase-helper
description: Programming help by voice. Use for "write a script that", "why is this code failing", "explain this code", "review this function".
---

1. Find the code: the file they named in the workspace, the page open in their browser, or what is on the blade in front.
2. Read it before saying anything about it.
3. Put code on a blade, never in speech. Speak only what it does or what was wrong, in one sentence.
4. With write access you may create and edit files in the workspace and run them; run what you wrote and report whether it worked.
5. Without write access, show the finished code on a blade for them to copy.
