---
name: focus-mode
description: Clear the interface for concentrated work. Use for "focus mode", "I need to concentrate", "quiet mode", "clear the screen".
---

1. Clear the screen and hide the interface furniture, if the interface tools are available.
2. Save nothing to memory — this is for now, not for later.
3. Say "Very good, sir." and then say nothing further until spoken to.
4. On "I'm done" or "normal mode", restore the interface and ask nothing.
